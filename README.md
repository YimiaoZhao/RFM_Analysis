# RFM E-commerce Customer Analysis

## 📌 项目简介
本项目基于电商交易数据，使用 **RFM 模型** 对客户进行分群分析，识别不同价值的客户群体，并针对性地提出营销策略，帮助商家提升用户留存与复购率。

## 📊 模型说明
RFM 模型是衡量客户价值和客户创利能力的经典工具，三个核心指标：
- **R (Recency) 最近一次消费**：客户最近一次购买的时间间隔，间隔越近，价值越高
- **F (Frequency) 消费频率**：客户在统计周期内的购买次数，频率越高，忠诚度越高
- **M (Monetary) 消费金额**：客户在统计周期内的消费总额，金额越高，价值越高

## 🎯 客户分群结果
通过 RFM 三个维度的打分，将客户分为 8 个核心群体：
| 客户群体 | R | F | M | 特征与营销策略 |
| :--- | :--- | :--- | :--- | :--- |
| 重要价值客户 | 高 | 高 | 高 | 核心高价值用户，重点维护，专属权益 |
| 重要保持客户 | 低 | 高 | 高 | 高价值但流失风险，需召回激活 |
| 重要发展客户 | 高 | 低 | 高 | 高客单价低频次，需提升复购 |
| 重要挽留客户 | 低 | 低 | 高 | 高价值沉睡用户，需精准唤醒 |
| 一般价值客户 | 高 | 高 | 低 | 高频低客单，需提升客单价 |
| 一般保持客户 | 低 | 高 | 低 | 高频低客单流失，需低成本维护 |
| 一般发展客户 | 高 | 低 | 低 | 潜力用户，需培养消费习惯 |
| 一般挽留客户 | 低 | 低 | 低 | 低价值用户，可减少投入 |

## 📈 核心结论与营销建议
### 核心结论
1.  核心高价值客户占比低，但贡献了大部分营收，是业务的核心支柱
2.  大量客户处于流失/沉睡状态，存在巨大的召回空间
3.  部分高潜力客户消费习惯未被充分挖掘，有提升空间

### 针对性营销建议
1.  **重要价值客户**：推出专属会员权益、定制化服务，提升忠诚度
2.  **重要保持/挽留客户**：发送专属召回优惠券、个性化推荐，唤醒消费
3.  **重要发展客户**：推出组合套餐、满减活动，提升购买频次
4.  **一般价值客户**：推出加价购、会员升级活动，提升客单价
5.  **低价值客户**：通过低成本内容营销、社群运营，筛选潜力用户
